## Overview

Tacab-AI is a versatile developer platform built with Flutter, enabling the creation of rich, cross-platform mobile and desktop applications. It integrates AI-powered chat, marketplace features, real-time weather updates, and localization, all within a scalable and maintainable architecture.

### Why Tacab-AI?

This project simplifies multi-platform app development by combining Flutter's UI capabilities with native integrations and cloud services. The core features include:

- 🌿 **Modular Architecture**: Clear separation of concerns for scalable development.
- 🌐 **Cross-Platform Support**: Seamless deployment across Android, iOS, Web, Windows, macOS, and Linux.
- 🔥 **Firebase Integration**: Real-time data, authentication, and cloud storage.
- 🎨 **Rich UI Components**: Reusable widgets, localization, and theming for a cohesive user experience.
- 🛠️ **Developer Tools**: Built-in linting, debugging, and streamlined setup to boost productivity.

## Getting Started

### Prerequisites

This project requires the following dependencies:

- **Programming Language**: Dart
- **Package Manager**: Pub, CMake, Gradle

---

### Installation

Build Tacab-AI from the source and install dependencies:

1. **Clone the repository:**

    ```bash
    git clone https://github.com/NF0mar/Tacab-AI
    ```

2. **Navigate to the project directory:**

    ```bash
    cd Tacab-AI
    ```

3. **Install the dependencies:**

   Using **pub**:
   ```bash
   pub get
   ```
